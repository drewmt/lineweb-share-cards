# Changelog

## 0.2.0

- Added Social Image Studio with source selection from published articles, pages, and catalog-visible WooCommerce products without changing the original content.
- Added Editorial, Split frame, Photo poster, and Type focus layouts with an exact PNG preview, single-image download, and all-four-format ZIP export.
- Added Story 1080 × 1920 to both the studio and existing Gutenberg block.
- Added administrator-managed brand defaults for colors, logo, and local system font, with an explicit Apply saved brand action for blocks.
- Added source authorization, preview/export error handling, long-text warnings, Greek translations, scoped studio assets, and desktop/mobile screenshots.
- Added browser, PNG/ZIP integrity, and WordPress permission regression coverage. Updated the transitive fast-uri lockfile dependency within its existing major version.
- Fixed Greek loading on WordPress's native `el` locale while retaining `el_GR` compatibility catalogs.

## 0.1.0

- Added one native dynamic Gutenberg block for quotes, key takeaways, statistics, and manually selected WooCommerce products.
- Added exact square, portrait, and landscape PNG generation inside the visitor's browser.
- Added optional logo, domain, source QR, custom caption, and four restrained visual presets.
- Added native image sharing with honest PNG download and caption-copy fallbacks.
- Added live WooCommerce title, price, stock, image, and product-link rendering without automatic placements.
- Added a centered Lineweb administration home, English and Greek catalogs, scoped assets, unit checks, browser journeys, release tooling, and public documentation.
