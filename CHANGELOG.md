# Changelog

## 0.1.0

- Added one native dynamic Gutenberg block for quotes, key takeaways, statistics, and manually selected WooCommerce products.
- Added exact square, portrait, and landscape PNG generation inside the visitor's browser.
- Added optional logo, domain, source QR, custom caption, and four restrained visual presets.
- Added native image sharing with honest PNG download and caption-copy fallbacks.
- Added live WooCommerce title, price, stock, image, and product-link rendering without automatic placements.
- Added a centered Lineweb administration home, English and Greek catalogs, scoped assets, unit checks, browser journeys, release tooling, and public documentation.
